Windows版 起動手順

1. 初回セットアップ
- `install_windows.bat` をダブルクリックしてください
- `[OK] Installation completed.` と表示されたら完了です

2. 通常の起動
- `start_windows.bat` をダブルクリックしてください
- 自動でブラウザが開きます
- 自動で開かない場合は `http://127.0.0.1:9000` にアクセスしてください

3. 停止
- `stop_windows.bat` をダブルクリックしてください

補足
- 「初回インストールがまだです」と表示された場合は、先に `install_windows.bat` を実行してください
- Python 3 が入っていない場合は、Python 3 をインストールしてから `install_windows.bat` を再実行してください
- このフォルダ内のファイルは、フォルダごとまとめて保管してください
